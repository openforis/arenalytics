# Analytical Dashboard for OpenForis Arena

function to launch the ShinyApp Arena Analytics. This app helps users to
explore their data from OpenForis Arena, gain insights and develop
report-ready figures and statistics.

## Usage

``` r
shiny_run_arenalytics(...)
```

## Arguments

- ...:

  arguments to pass to shinyApp

## Examples

``` r
if (interactive()) {

shiny_run_arenalytics()

}
```
